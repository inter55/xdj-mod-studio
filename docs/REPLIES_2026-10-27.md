# Reddit replies after v1.0 prep (2026-10-27) — paste-ready

The four reports from the 0.99 comments are addressed in 1.0 (see
RELEASE_NOTES.md "What changed in 1.0"). Drafts below: English summary
first, then Italian for u/InternationalElk5378 and German for
u/yupiyupijupjupjup.

## English (summary reply under the post)

Thanks for the reports — all four are looked at for 1.0:

- **RGB centre waveform turning blue after a while** (and coming back
  after a CUE jump): found it. The waveform colour data's entry count was
  read as 16-bit, so on any track longer than ~7:17 the count wrapped and
  the colour fell back to stock part-way through the track. Fixed in 1.0
  (verified against the format on real sticks: 28 of 263 tracks on my own
  test stick were affected).
- **The RGB waveform not sitting on the beat grid** (blue / 3-band fine):
  same area — the colour data's own rate is now read from the file and
  scaled to the deck's grid, instead of assuming 150 columns/s.
- **Hot cue pages D–F / G–H doing nothing**: two things. The paging code
  now also accepts the letter-coded cue entries newer rekordbox versions
  write. But the most common cause is the stick, not the deck: the deck
  reads hot cues from the track's **exported analysis**, so if you set the
  cues in rekordbox *after* exporting the stick, the deck never sees them.
  1.0's Track Builder shows an "A–H" tag on every track whose export
  carries 4+ cues — if a track doesn't get the tag, re-export the stick in
  rekordbox and the pages will work.
- **Stems**: the app's stems list had a bug (it looked for an older file
  format only, so it always showed empty) — fixed. And on the deck, the
  (STEMS) file is **not** in the Track/Artist lists, because it is not in
  the rekordbox export: press BROWSE and scroll to the **bottom** category
  (FOLDER), then open the track's folder — the file is next to the
  original. Load that one and PERFORM › STEMS mutes the parts.

## Italian (u/InternationalElk5378)

Grazie del report, ho trovato i problemi — tutto sistemato nella 1.0:

- **RGB che dopo un po' torna blu** (e col CUE ritorna): era un bug
  nostro — il numero di colonne dei dati colore veniva letto a 16 bit, e
  sulle tracce più lunghe di ~7:17 andava in overflow. Fissato.
- **Griglia disallineata solo con la banda RGB**: stessa zona: ora la
  densità dei dati colore viene letta dal file e riscalata sulla griglia
  del deck, invece di assumere 150 colonne/sec.
- **Pagine hot cue D–F / G–H**: il deck legge le hot cue **dall'analisi
  esportata sulla chiavetta**. Se hai impostato le 8 cue in rekordbox
  *dopo* aver esportato la USB, il deck non le vede: rifai l'export della
  chiavetta da rekordbox e le pagine funzioneranno (il tap sul tab HOT
  CUE cambia pagina). Nella 1.0 il Track Builder mostra un tag "A–H" sulle
  tracce che hanno 4+ cue nell'export, così si vede subito.
- **Stems**: due cose. Nell'app la lista "stems files" era sempre vuota
  per un bug (cercava solo un formato vecchio) — fixed. E sul deck: il
  file **(STEMS).wav NON compare nelle liste Traccia/Artista**, perché non
  fa parte dell'export rekordbox. Premi BROWSE e scorri le categorie fino
  in fondo (**FOLDER**), entra nella cartella del brano: il file è lì
  accanto all'originale. Carica quello, e in PERFORM › STEMS puoi mutare
  vocals/drums/bass/other.
- **Cambio di tonalità**: è ancora beta e **spento di default** — va
  spuntato nella pagina Mod dell'app, e richiede **MASTER TEMPO attivo**
  (senza MT il tab mostra "MT OFF" e non fa nulla, by design: senza MT il
  deck risampla e la tonalità cambierebbe anche il tempo). Se lo spunti,
  accendi MT e ancora non funziona, mandami il log dell'installazione e
  dimmi che formato era il brano (WAV/AIFF/MP3?).

## Older tester reports (0.9.5-0.99 round-up, same thread)

- **3-Band falls back to blue** (0.9.5/0.9.8 Windows): not a broken
  setting -- 3-BAND only draws on tracks whose exported analysis carries
  the 3-band data (PWV7). Track Builder > Add 3-band writes it (per-track
  Ready / In rekordbox / Missing tags there). The tester on 0.99 who
  reports "RGB und 3Band laufen" had run it once. Now also spelled out in
  the release notes (Known issues).
- **Waveform / phase meter only on the deck holding the USB stick (Pro DJ
  Link)**: known, honestly listed as "not in 1.0" -- the linked deck loads
  the track over Link and never sees the analysis data our mods read.
  Link support is the next big item after 1.0.
- **"Track not synchronised with the waveform" (0.99)**: same root cause
  as the blue-revert -- past the 7:17 mark the colour data runs out of
  step. Fixed in 1.0.
- **Hot cues only A-C**: paging hardened + Track Builder now shows a
  per-track "A-H" tag when the exported analysis really carries 4+ cues.
  If the tag is missing: re-export the stick in rekordbox -- cues set
  after the export never reach the deck.
- **Feature pick / bigger pads**: the Mods page has been tick-box per
  feature since 0.99 (just leave Stems and Key Shift unticked), and 1.0
  also hides the KEY SHIFT / STEMS tabs on the PERFORM screen when those
  mods aren't installed — so with Beat Jump + Hot Cues only you get no
  dead tabs. Pads that grow to fill the freed space is still a good 1.1
  idea -- noted.
