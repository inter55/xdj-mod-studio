## Follow-up for anyone with Touch FX (found 2026-11-09 night, fix not released yet)

Found a real bug in Touch FX's Filter: with the finger at the far right of
the pad (filter fully open) and the resonance low, the filter goes unstable and the deck puts out full-volume noise; on a real
deck that can lock up the audio. Fixed in the next version. Until then:
avoid the far-right edge in Filter, or leave Touch FX unticked.

## 3-band still blue (deck + Windows emulator), 2026-11-10 -- not posted

Thanks for the report. Most likely nothing is broken, the app just never
told you about a step: 3-band is per track. rekordbox stores the 3-band
colours in a file the XDJ-700 never reads, so each track has to be prepared
once:

1. Open Mod Studio > Track Builder and choose your USB stick.
2. Press "Add to all" in the yellow bar (or the "Needs 3-band" filter, then
   Add 3-band).
3. Eject the stick properly, put it in the deck and load a track again.

Tracks that haven't been prepared stay blue even with the setting on
3-BAND, and the emulator shows the same thing because it reads the same
stick. The next version says this wherever you pick 3-band.

If Track Builder says a track is "Missing" (not "Can add"), rekordbox didn't
export 3-band data for it; Mod Studio can work it out from the audio but
needs ffmpeg for that (Windows: `winget install ffmpeg`, then restart Mod
Studio).

If it is still blue after that, tell me: your rekordbox version, what the
3-Band column in Track Builder shows for that track, and whether RGB works.
