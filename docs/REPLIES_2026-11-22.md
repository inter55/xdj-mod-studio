## 1. Stick user ("reinstalled 1.1.2 mods, same thing, has to load the cues again")

Thanks, that matches what I found. It isn't your stick and reinstalling won't
change it. When you page to D–F/G–H and back, the deck treats the paged cues
as "not loaded yet", so the first press on a pad loads it (that's the short
pause) and the second press is instant. 1.1.1 fixed it for pads you didn't
touch on the other page, but any pad you used over there still reloads once.

## 2. Cable tester (key shift, Touch FX, OTHER, D-H markers)

Thanks for the detailed notes.

- **Key shift:** it only works with MASTER TEMPO switched ON. With MT off,
  the panel should show "MT OFF". Can you try it with MT on? If it still does
  nothing, please send the Activity > Details log from the install.
- **Touch FX / empty tab:** HOT CUE, BEAT JUMP, [empty], STEMS is the layout
  you get when the Touch FX screen did NOT install. Key Shift and Touch FX
  share the same slot in the audio chip, so the app installs one or the
  other: whichever you ticked last wins. If you ticked Touch FX and still got
  the empty slot, the install skipped the screen and only printed one line
  about it. The next version stops with a clear warning instead. Please
  switch the deck off and on, install again with only Touch FX ticked, and
  send the log if the slot is still empty.
- **"OTHER":** it's everything that isn't vocals, drums or bass: synths,
  keys, guitars, pads, FX. OTHER mutes all of that at once. It doesn't delete
  anything; tap it again to bring it back.
- **D-H delay:** the first press after changing page loads the cue, which is
  the delay you notice. Same answer as above; I'm working on preloading them.
- **D-H on the bar:** the deck only has three cue markers, so they show the
  page you're on. Showing all eight at once in different colours means
  drawing five extra markers ourselves. Good idea, it's on the list.
