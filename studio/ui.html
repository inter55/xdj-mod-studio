Pick your mods

Colour Waveforms
RGB and 3-band colours for the overview strip and the big centre waveform. You pick the style on the deck: hold MENU › UTILITY › WAVEFORM COLOR.
PERFORM Pads
BEAT JUMP, KEY SHIFT and STEMS tabs on the PERFORM screen, plus 8 hot cues: swipe along the HOT CUE tab (or tap it in the PERFORM screen) to page A–C / D–F / G–H.
Live Key Shift
PERFORM › KEY SHIFT shifts any track −6…+6 semitones while it plays, tempo unchanged (MASTER TEMPO on). Installed live into the deck's audio chip (no restart, the sound never stops), with the stick out. Tested on a real deck: the key moves, the tempo stays.
Phase Meter (beta)
Type 1 meter (like the XDJ-1000MK2): this deck's beats and downbeats scroll past a fixed line above the waveform, on the main screen and the PERFORM screen. Needs PERFORM Pads. The master row stays dim until Pro DJ Link support lands. Not yet tested on a real deck.
Themes
All your saved themes (make your own in Theme Builder). Pick one on the deck: hold MENU › UTILITY › THEME. OFF puts the stock colours back exactly.
FLAC Playback
Only needed if your library has .flac files: they then list and play like WAV. Ticked for you when your stick has any (checking the stick…). Opus (.opus) support is added only when your stick has .opus files.
Styles, themes, vinyl brake length and the hot cue gate are chosen on the deck itself: hold MENU › UTILITY (scroll to the end).
Everything runs in the deck's memory — power-cycle the deck and it's stock again. Nothing here can brick it.

How it works

Safe?
Nothing is flashed: mods load into the deck's memory (power-cycle = stock), every write is verified and it stops at the first surprise. Track Builder does write to your USB stick, keeping backups; the Permanent (UPD) tab is the one exception that makes a file to flash.
Undo
Power-cycle the deck. That's it.
After install
Hold MENU › UTILITY and scroll to the end: MODS, WAVEFORM COLOR, VINYL BRAKE LENGTH (0.5×–15×), HOT CUE GATE and THEME — push, turn, push to change, like any stock setting. If the colours or phase meter ever look gone: check WAVEFORM COLOR is not BLUE and MODS is ON there.

Danger zone: this makes a FIRMWARE file you flash yourself.
Every other mod in this app lives in the deck's memory, and switching the deck off and on removes it. A permanent update does not go away when you switch off.
  • It can brick your deck. A bad file, a power cut or pulling the stick mid-update can leave the XDJ-700 needing a Pioneer DJ service centre.
  • Never tested on a real deck yet. Every file is boot-tested in the emulator before you get it, but the emulator cannot prove a real flash.
  • No warranty. Pioneer DJ / AlphaTheta do not support modified firmware.
  • The way back is to flash the official v1.15 file, so keep it on a second stick.

1. Your official update file

The XDJ700.UPD for firmware 1.15 from Pioneer DJ's XDJ-700 support page. Anything else is refused.

2. What to bake in

Baked-in mods stay on the deck after power-off.
Presets:
Overview waveform
Extras: the file carries them and a small start-up routine copies them into the deck's memory every time it switches on.
Baked into the file
  • Overview waveform (blue, RGB or 3-band)
  • PERFORM tabs and beat jump pads (if ticked)
  • Mod settings in UTILITY (hold MENU): MODS, WAVEFORM COLOR, VINYL BRAKE LENGTH, HOT CUE GATE (always)
  • The extras you ticked above (live stems and 8 hot cues need the PERFORM pads)
  • Version 1.16 in UTILITY, so you can tell it apart
Can't be baked: install over USB from Mods
  • Live themes (UTILITY › THEME needs it)
  • FLAC & Opus playback
Each is bigger than the free space left in the firmware file (themes need about 42 KB even for one theme, FLAC & Opus about 120 KB; the file has about 27 KB free).

3. I understand

Takes about 5 minutes. The file goes to Downloads / “XDJ700 modded update”, with a READ ME FIRST.
The app only builds the file and boot-tests it in the emulator. It never flashes your deck. You run the update yourself, the normal Pioneer way.

Updates

You have version . The app checks GitHub for a newer release; nothing is downloaded until you press the button.
Checking…
The download goes to your Downloads folder. Quit the app, open the zip and drag the new app over the old one. Your settings, firmware setup and themes are kept.

Appearance

Light or dark app colours. System follows your computer's setting.

Library

The USB stick or rekordbox export folder (the one holding PIONEER). Used by Track Builder and by the emulator's USB stick.

Project folder

Holds your themes (mods/themes.py), the mod tools, the prebuilt deck modules, cache and build, and your official update file. Studio works from a default folder (inside the app on the Mac; the repo folder next to XDJ Mod Studio.exe on Windows); a folder of your own keeps your themes and firmware where you can see and back them up.
Default folder (the folder inside the app):
Your own project folder in four steps
  1. Make an empty folder anywhere, for example Documents/XDJ Project.
  2. Type or choose its path below and press Set up this folder: Studio copies the mods, tools, prebuilt deck modules and the audio-chip disassembler into it (nothing you already have there is overwritten).
  3. Put your official XDJ-700 v1.15 update file in that folder as XDJ700.UPD (or FIRMWARE/XDJ700_stock_v1.15.UPD). Studio copies it for you when it already knows the file from the Permanent firmware page. It is never bundled with the app.
  4. Quit and reopen Studio. Reset to default goes back to the default folder at any time; your own folder is left untouched.

Stem separation

About 2–3 GB, on Wi-Fi, in its own environment. Needs Python 3.11/3.12 and ffmpeg (Mac: brew install python@3.12 ffmpeg; Windows: Python 3.12 from python.org + winget install ffmpeg).
